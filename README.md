# KisaanConnect

## Overview

KisaanConnect is a Java EE web application that connects farmers and buyers through an online marketplace. Farmers can list agricultural products, buyers can browse and purchase them, and administrators can manage the platform.

## Technologies

- Java EE
- JSP
- Servlets
- JDBC
- MySQL
- HTML
- CSS
- JavaScript
